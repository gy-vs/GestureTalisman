# 通天箓 - 手势互动符箓系统

基于《一人之下》动漫中"通天箓"概念打造的沉浸式手势互动体验。通过摄像头进行手势识别，实现虚空画符、手势召唤、符纸燃烧等炫酷交互效果。

---

## 快速启动

### Docker 方式（推荐）

```bash
# 构建并启动（首次构建会下载AI模型，约30MB）
docker compose up --build -d

# 访问
open http://localhost:8088
```

**优势**：Docker 镜像已预载 MediaPipe 手势识别模型，启动后**无需联网下载**，加载速度更快。

### 本地开发

由于需要摄像头权限，建议使用本地 HTTP 服务器：

```bash
# 使用 Python
python -m http.server 8088

# 或使用 Node.js
npx serve -p 8088

# 访问
open http://localhost:8088
```

> 注意：本地开发模式需要联网，首次加载会从 CDN 下载模型文件。

## 功能特性

### 🎨 虚空画符

伸出食指在空中画出符文图案，系统会识别并释放对应元素的特效。

| 符箓 | 图案 | 特效 |
|-----|------|------|
| 🔥 火符 | 三角形向上 | 烈焰焚天 |
| 💧 水符 | 波浪线 | 沧海横流 |
| 🌿 木符 | Y形向上 | 万物生长 |
| ⚡ 金符 | 闪电折线 | 刀光剑影 |
| 🌍 土符 | 正方形 | 地动山摇 |
| ❄️ 冰符 | 六边形 | 冰封万里 |
| 💜 雷符 | 双折线 | 天雷滚滚 |
| 🌸 风符 | 螺旋线 | 落英缤纷 |

### 🤟 手势召唤

无需画符，特定手势保持2秒直接召唤符箓！

| 手势 | 符箓 |
|------|------|
| ✌️ 比耶（食指+中指） | 🔥 火符 |
| 🤙 比6（拇指+小指） | ❄️ 冰符 |
| 👌 OK手势 | 💧 水符 |
| 🤟 摇滚（拇指+食指+小指） | 💜 雷符 |
| 🌿 三指（食指+中指+无名指） | 🌿 木符 |
| 👍 点赞（仅拇指） | 🌸 风符 |
| ✊ 握拳 | 🌍 土符 |

### 🖐️ 符箓环绕

| 手势 | 操作 |
|------|------|
| 🖐️ 张开手掌 (1.5秒) | 召唤符箓环绕 |
| ☝️ 单指指向 | 选择符箓 |
| 🤏 捏合 | 提取选中的符箓 |
| 🖐️ 再次张开 | 激活符箓 |
| 👋 招手 | 取消/退出 |

### 📜 符纸燃烧动画

符箓激活时的完整流程：
1. **符纸展现** - 传统道教风格符纸从虚空中现身
2. **符纸燃烧** - 火焰从底部向上蔓延，符纸逐渐被吞噬
3. **激活特效** - 对应元素的华丽全屏特效

### 🎮 模拟测试模式

无摄像头？按 `M` 键启用模拟模式，用鼠标和键盘体验完整功能。

## 技术栈

- **手势识别**: MediaPipe Hands (21关键点追踪)
- **渲染引擎**: Canvas 2D + CSS Animation + SVG
- **图案匹配**: $1 Recognizer 变体算法
- **特效系统**: CSS动画 + 精简粒子引擎
- **容器化**: Docker + Nginx Alpine

```
├── docs/
│   └── SelfTestReport.md  # 自测报告
├── assets/                 # 资源文件（可选）
├── docker-compose.yml
├── Dockerfile
└── nginx.conf
```
